CAREERSENSE — ANTIGRAVITY MASTER BUILD PROMPT

1. PROJECT OVERVIEW

I want to build a polished, hackathon-ready web application called CareerSense.

The core problem:

Students often learn random technologies from YouTube, courses, bootcamps, and social media without knowing:

- What should I learn next?
- Am I actually job-ready?
- Which skills am I missing?
- What projects should I build?
- How should I prepare for a specific role?
- What should my learning roadmap look like?

SOLUTION

CareerSense is an AI-powered career and learning platform where a student provides:

- Current skills
- Projects
- Interests
- Target career role

The application analyzes their current profile and generates:

- Skill gaps
- Job-readiness insights
- Personalized learning roadmap
- Relevant project recommendations
- Resume/portfolio improvement suggestions
- Interview preparation

The goal is to make CareerSense feel like a personal AI career mentor, not simply an AI chatbot.

--------------------------------------------------
13. AI ARCHITECTURE
--------------------------------------------------

DO NOT call the LLM directly from the React frontend.

Use:

React
↓
Express Backend
↓
AI Service
↓
LLM API

The API key must remain server-side in environment variables.

Example:

.env

LLM_API_KEY=...

Never expose API keys in:

- React source code
- client-side environment variables
- GitHub repository
- frontend network requests

Create a separate AI service/module so that the LLM provider can be replaced later without rewriting the entire application.
